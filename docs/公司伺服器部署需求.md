# 特案支援金報備系統 — 移轉到公司伺服器需求清單

現況：程式碼放 GitHub 個人帳號、資料庫用 Vercel + Neon Postgres（雲端），要整組移轉到公司自有伺服器（程式碼＋資料庫都要搬）。

## 1. 原始碼／GitHub

- Repo：https://github.com/toyotad820/special-fund-approval（目前 **Public**、掛在個人帳號 `toyotad820`，非公司組織帳號）
- 需要決定：
  - 轉移到公司 GitHub 組織帳號，或至少改成 Private
  - 誰接手 admin 權限（目前只有這個個人帳號有完整權限）
  - 若公司內網無法連外部 GitHub，需改用公司內部 Git 服務（GitLab/內部 Git），可用 `git clone --mirror` 完整搬移 commit 歷史後 push 到新地址

## 2. 執行環境

- Node.js ≥ 20.9（建議 LTS 22 以上）
- npm
- Linux / Windows 皆可（Next.js 16 標準支援）

## 3. 資料庫

- PostgreSQL（建議 14+）
- 需要一組新的 `DATABASE_URL`（公司資料庫的帳密／host／port／DB 名稱）
- 目前正式資料在 Vercel + Neon Postgres，**357+ 筆真實案件資料**，需要搬過去（見第 6 節）

## 4. 環境變數

| 變數 | 說明 |
|---|---|
| `DATABASE_URL` | 新資料庫連線字串 |
| `SESSION_SECRET` | 隨機字串，至少 32 字元，正式環境專用，不可沿用開發值 |

## 5. 建置與啟動指令

```bash
npm install
npx prisma generate --schema=prisma/schema.production.prisma
npx prisma db push --schema=prisma/schema.production.prisma
npm run build
npm run start          # 預設 port 3000，需搭配反向代理對外
```

## 6. 資料轉移（Neon → 公司資料庫）

- 用 `pg_dump`（來源 Neon）＋ `pg_restore`（目的地公司 DB），或請開發方寫轉移腳本直接搬
- 轉移前先備份一份（另有一份匯入前的舊資料備份可對照）
- 需確認公司資料庫網路是否對執行轉移的機器開放連線

## 7. 網路需求

- 對外／對內網域＋HTTPS 憑證
- 反向代理（nginx／IIS）轉發到 Node 服務 port
- 內網存取限制規則（如需要）

## 8. 安全性（上線前必做）

- 所有測試帳號密碼統一 `1234`，正式員工帳號上線前必須更換
- `SESSION_SECRET` 換成正式環境專用隨機值
- Repo 改 Private（若尚未改）

## 9. 持續維運

- 更新流程：`git pull` → `npm install` → `npm run build` → 重啟服務，或串公司 CI/CD
- 目前用 `vercel.json` 設定建置指令，換平台需改寫成對應格式（如 Dockerfile、GitHub Actions 等）
